chimpread Connector

Connect your library

  1. In chimpread, press ⌘, and enable Chrome Connector.
  2. Use the extension on a publisher page to save its citation or PDF. Keep chimpread open to process the inbox.
  3. Search your library to copy citations or bibliographies.

Google Docs — one-time setup

This local development extension has no shared Google OAuth credentials. Configure your own Google Cloud project. No client secret is needed.

  1. Enable the Google Docs API in your Google Cloud project.
  2. Configure the OAuth consent screen, add yourself as a test user if using testing mode, and request the Google Docs scope.
  3. Create an OAuth client of type Chrome Extension using the extension ID below.
  4. Run the provided configure_google.py CLIENT_ID script in the source ChromeExtension folder, then load or reload that folder in chrome://extensions.
  5. Open a Google Doc, select papers in the extension, and choose Preview insertion. Google will ask you to authorize access.

Inserting citations

Type {{cite}} exactly once at the desired position in your document tab. Preview and insert to replace that marker. Bibliographies append at the end of the selected tab. These are plain-text entries: changes to references or styles do not automatically update previously inserted text. Nature numbering restarts for each selected citation group; use APA for separate insertions unless you manage numbering yourself.

Data access

Page extraction happens only when you open the extension. Chrome receives library citation metadata, never your PDF annotations or note drafts. Requested PDFs download into Downloads/chimpread, then the app copies them. Google receives only the bibliography or citation you explicitly insert. The Google Docs permission permits reading and editing documents; the connector accesses only the document you preview. No analytics or third-party backend.

The native bridge starts per request and opens no network port. Disable it in chimpread Integrations to revoke access.
